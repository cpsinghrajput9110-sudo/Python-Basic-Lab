Python Basics Lab
Overview
This repository contains Python programs demonstrating basic concepts of Python programming.

Programs Included
1. Factorial Calculator
Calculates the factorial of a given number.

2. Fibonacci Series
Generates the Fibonacci sequence for a specified number of terms.

3. C Structure to Python Dictionary
Demonstrates how a C structure can be represented using a Python dictionary.
